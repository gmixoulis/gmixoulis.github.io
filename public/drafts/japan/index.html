Font licensing notes

No Adobe Typekit / Fonts kit ID is present in this repository. Commercial face files (Kokuryu / KokuryuSou, Harukaze Brush) are not embedded. Drafts use free Google Fonts stand-ins, labeled for production swap.

Intended commercial faces

  • Kokuryu / KokuryuSou (Adobe Fonts, Showashotai) — fonts.adobe.com/fonts/kokuryu — brush dragon energy for seals / atmospheric JP type.
    Swap path: add Adobe Fonts web project → load kit → replace --font-brush-display
  • Harukaze Brush — allfreefonts.co/harukaze-brush-font — brush hand for short inscriptions.
    Swap path: license/host legally → replace --font-brush-hand

Free stand-ins (shipping now)

  • Yuji Boku → KokuryuSou stand-in (brush display / seals)
  • Zen Kurenaido → Harukaze Brush stand-in (hand inscription)
  • Shippori Mincho → Latin + JP display for the name lockup
  • Source Sans 3 + Noto Sans JP → body / meta
